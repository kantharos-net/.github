# kantharos-net

Projects under active development and maintenance.

## Projects

- [**certharbor**](https://github.com/kantharos-net/certharbor) — self-hosted internal CA and certificate lifecycle manager, built on `step-ca`. Go backend, React SPA, and generated TypeScript, Java, and Ruby clients published from one committed OpenAPI contract.
- [**manifold**](https://github.com/kantharos-net/manifold) — self-hosted personal finance hub: aggregates bank accounts via open banking (TrueLayer), syncs transactions, detects recurring payments, and fires configurable alarms over email, Slack, and Telegram. Node.js + React, Dockerized.

More to follow as they move in.
